# 회차장부

개인 레슨의 출결·특이사항과 선택적인 수업료 관리를 지원하는 Flutter 휴대폰 앱. 서버 없이 기기에 저장한다.

## 구현 범위
- 수업권 없이 날짜별 완료·미완료 기록, 선택적인 특이사항과 과거 기록 정정
- 기본 시작 시간과 수업별 날짜·시간 변경, 학생 수업 종료는 별도 메뉴
- 수업료 관리는 하단 선택 기능으로 분리
- 학생 상세에서 메모 바로 저장, 홈에서 메모 미리보기
- 사용자 정의 과목과 전체 기본 필터, 주/월 목표 횟수, 정기 요일, 이번 주 실제 수업·예정 확인
- 학생 등록·검색·수업 종료·재시작, 수업권과 기존 사용 회차/입금 등록, 사유를 남긴 수업권 수정
- 수업 예정·완료·연기·취소·결석 차감·사유를 남긴 되돌리기
- 부분 입금·입금 취소, 남은 회차·잔액·변경 이력
- 안내문 시점별 저장, 복사·텍스트/PNG 공유
- 비밀번호 암호화 백업/복원, 수업권 요약 CSV, 장부 전체 삭제
- 무료 활동 학생 5명, 일회성 Pro 결제 및 구매 복원 연결

결제 상품과 계정이 준비되지 않은 빌드는 구매를 열지 않는다. 실제 결제 성공을 가장하는 데모 기능은 없다. 수익이나 스토어 승인이 검증된 상태는 아니다.

## 실행·검증
```powershell
flutter pub get
dart analyze --format machine lib test
flutter test --no-pub
flutter build apk --debug
```

Android API 24 이상, iOS 배포 타깃 15.0. iOS 컴파일과 기기 실행은 Windows에서 검증하지 않았다. 현재 환경의 한글 경로 분석 도구 오류 및 출시 서명 설정은 [빌드 설명](docs/BUILD.md)에 기록했다.

## 저장과 범위 제한
장부는 앱 전용 JSON과 직전 저장본으로 보관한다. 저장 성공 뒤 화면 상태를 바꾼다. 직전 저장본을 읽었을 때 복구 알림을 표시하며, 둘 다 손상되면 백업 복원 화면을 연다. 장부 파일은 UTF-8 기준 20MB까지 저장한다. 초과 저장은 기존 데이터를 바꾸지 않고 거부한다.

백업 비밀번호는 10자 이상이다. 비밀번호 분실 시 복구할 수 없다. 앱 삭제 전에 외부 위치에 백업해야 한다. 무료 상태에서 6명 이상 백업을 복원하면 확인 후 처음 5명만 활동 상태로 두고 나머지 기록은 보관한다. 긴 안내문은 이미지 생성 한도를 넘으면 텍스트 공유를 안내한다.

은행 입금 자동 확인, 자동 메시지 발송, 여러 기기 실시간 동기화, 광고·분석 SDK는 포함하지 않았다.
